# Stock-Market-Analysis-Dashboard
This project is an end-to-end stock market analytics pipeline built using Python, Alpha Vantage API, MySQL, and Power BI

#Analysis Shown in the Dashboard
- Stock price trends
- Moving averages (MA_20)
- Trading volume
- Daily stock returns

#Project Pipeline
  -Alpha Vantage API → Python → Pandas → MySQL → Power BI Dashboard

#Features
- Real-time stock data extraction using API
- Data cleaning and preprocessing
- MySQL database integration
- Interactive Power BI dashboard
- Moving Average analysis
- Daily Return analysis
